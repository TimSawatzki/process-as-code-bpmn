# QA Engineer Role Definition

QA Engineers ensure that the software release complies with functional, regression, security, and performance standards. They run test plans and compile verification reports.

## Key Responsibilities
*   **Test Case Authoring:** Write and maintain end-to-end integration and system tests.
*   **Staging Validation:** Perform manual exploratory testing and execute automated regression test suites on the Staging environment.
*   **Report Generation:** Log test summaries and document defects. Generate the official [Test Report](file:///Users/timsawatzki/.gemini/antigravity/scratch/process-as-code-bpmn/docs/artifacts/test_report.md).
*   **Blocker Escalation:** Immediately raise issues that halt the release pipeline.

## Access Levels
*   **Write Access:** Testing frameworks, QA environments, bug tracking systems.
*   **Read Access:** Application repository, CI build logs, staging databases.

## Process Touchpoints
1.  **Staging Deployment & QA Verification:** Primary actor. Reviews deployment, runs tests, and signs off.
