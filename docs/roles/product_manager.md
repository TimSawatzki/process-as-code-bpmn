# Product Manager (PM) Role Definition

Product Managers align process goals with user needs. They oversee release feature scopes, verify functional requirements, and participate in final release approvals.

## Key Responsibilities
*   **Scope Definition:** Establish release goals and write Product Requirement Documents (PRDs).
*   **PR Review Sign-off:** Join technical reviews for critical changes to verify features meet product specs.
*   **Staging Validation:** Review the staging environment alongside QA to verify user experience details.
*   **Release Approval Support:** Act as a key advisor to the Release Manager on whether release objectives are met.

## Access Levels
*   **Read Access:** Source code repositories, PR dashboards, QA test suites.
*   **Write Access:** Product tracking tools (Jira, Linear) and release documentation.

## Process Touchpoints
1.  **Code Review & PR Approval:** Secondary reviewer for business logic alignment.
2.  **Staging Deployment & QA Verification:** Co-sign off on visual and UX checks.
